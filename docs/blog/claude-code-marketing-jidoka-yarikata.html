Claude Codeでマーケティングを自動化するやり方｜導入5ステップと承認つき運用

公開: 2026-10-02 ・ 更新: 2026-10-02 ・ MOAI 編集部

要点
  • Claude Codeは、日本語の指示でファイルの読み書き・調べもの・コマンド実行までこなすAnthropicのAIエージェント。マーケティングでは調査・下書き・レポート作成の自動化に向く
  • 自動化で詰まりやすいのは「指示が毎回ばらばら」「生成物が散らばる」「勝手に公開される不安」の3点。指示の置き場と承認の関門を先に作ると安定する
  • オープンソースのMOAIを使うと、画面で積んだ指示を Claude Code が順に処理し、生成物は承認キューに戻る。承認していないものは公開されない
  • 導入は「clone → node server.js → スキルとエージェントのコピー → 1回だけログイン → ▶ AIに実行させる」の5段階

Claude Codeをマーケティングに使いたいと考えたとき、多くの人が最初につまずくのは「何から任せればいいか」と「どう運用に組み込むか」です。チャット画面で1回ずつ頼むだけなら手軽ですが、毎週の記事企画や競合調査を継続して任せるには、指示の書き方、生成物の置き場所、公開前の確認の仕組みを決めておく必要があります。

この記事では、Claude Codeでマーケティング業務を自動化するやり方を、オープンソースのAIマーケティング司令室「MOAI」と組み合わせる手順で説明します。コマンドはすべてMOAIのリポジトリに実在するものだけを使っています。

Claude Codeとは何か、マーケティングで何を任せられるか

Claude Code は Anthropic が提供するAIエージェントで、ターミナルやデスクトップアプリから、日本語の指示でファイルの読み書き、Web検索、コマンドの実行などを行えます。提供形態・利用条件・料金は Claude Code の公式ページと 公式ドキュメントで確認してください。

マーケティング業務で任せやすいのは、次のような「材料を集めて、決まった形にまとめる」仕事です。

業務任せる内容の例人が残すべき判断
SEO調査狙うキーワードの検索結果の傾向、上位記事の見出し構成の整理どのテーマを書くか
記事の下書き構成案、本文の下書き、FAQ案事実確認、公開の可否
SNS投稿文1本の記事から投稿文の案を複数作るトーン、投稿するかどうか
競合調査公開情報から競合の発信テーマ・頻度を整理自社の打ち手
週次レポート記録した実績の推移のまとめと次週の候補優先順位の決定

反対に、外部サイトへの投稿、メールの送信、広告費の操作のように、取り消しが難しい作業は、自動化の対象から外すか、人が最後に確認する形にするのが安全です。

自動化が続かない3つの理由と対策

1. 指示が毎回ばらばら

ブランドの方針やトーン、禁止事項を毎回書かないと出力の質が揺れ、書くのが面倒になって続かなくなります。対策は、前提を1か所に書いておき、毎回の指示に自動で付けることです。MOAIでは「設定」画面のミッション・トーン・禁止ワード・運用ルールがこの役割を持ち、Claude Codeは処理の最初に node cli.js context でこれを読み込みます。

2. 生成物が散らばる

チャット履歴やフォルダに生成物が散らばると、どれが確認済みで、どれを公開したのか分からなくなります。対策は、生成物を必ず1つのキューに戻すことです。MOAIでは生成物は「承認待ち」のタスクとして承認キューに入り、承認済み→公開済みまで状態で追えます。

3. 勝手に公開される不安

AIに権限を渡しすぎると、確認していない文章が外に出る不安から、結局すべてを手作業に戻しがちです。対策は、AIの権限を絞り、公開の前に人の承認を必ず挟むことです。MOAIの同梱スキルは「承認されていないタスクを勝手に公開してはいけない」というルールで動き、実行時の権限も既定では絞られています（後述）。

導入手順

必要なもの

  • Node.js（無料）
  • Claude Code（利用条件は公式の案内を確認）
  • git（なくても、GitHubから「Download ZIP」で取得できる）

ステップ1：MOAIを取得して起動する

git clone https://github.com/solederlego8-a11y/moai.git
cd moai
node server.js

ブラウザで http://localhost:4173 を開くと画面が出ます。停止は Ctrl + C です。Windowsでは start-moai.bat のダブルクリックでも起動します。依存パッケージはないため npm install は不要です。

ステップ2：スキルとAIエージェントを Claude Code に入れる

リポジトリの claude-code/ フォルダに、MOAIの実行手順を書いたスキルと、役割別のAIエージェント定義が入っています。これを Claude Code の設定フォルダにコピーします。

# Windows
xcopy /E /I claude-code\skills\moai "%USERPROFILE%\.claude\skills\moai"
xcopy /E /I claude-code\agents "%USERPROFILE%\.claude\agents"

# macOS / Linux
cp -r claude-code/skills/moai ~/.claude/skills/
cp -r claude-code/agents/* ~/.claude/agents/

コピーされるエージェントは、SEOリサーチャー（moai-seo-researcher）、コンテンツライター（moai-content-writer）、SNSコピーライター（moai-social-copywriter）、競合アナリスト（moai-competitor-analyst）、グロース分析官（moai-growth-analyst）、収益ファネル設計（moai-funnel-designer）、動画・Reels企画（moai-video-director）の7つです。画面上の「戦略ディレクター」はスキル自身（メインの処理）が担当するため、AIチームは合計8人になります。

ステップ3：最初に1回だけログインする

MOAIは画面のボタンから Claude Code を起動します。そのために、一度だけログインが必要です。

  • Windows：login-claude.bat をダブルクリック
  • macOS / Linux：node login.js

ブラウザが開くので許可（Authorize）を押します。状態は node login.js --status でいつでも確認できます。デスクトップアプリでログイン済みでも、この手順は別に必要です（アプリの認証は、外部から起動したAIには引き継がれないため）。

ステップ4：前提を書き、指示を積む

  1. 「チャネル」で運用するメディアを登録する
  2. 「設定」でミッション・トーン・禁止ワード・運用ルールを書く
  3. 「指示する」で依頼を日本語で書き、担当（AIチームの誰か、または「おまかせ」）と対象チャネルを選んでキューに積む

ステップ5：「▶ AIに実行させる」を押す

「指示する」画面の「▶ AIに実行させる」を押すと、サーバーが Claude Code を起動し、キューの指示を古い順に処理します。どのツールを使い、何を調べているかが画面にそのまま表示されます。生成物は承認キューに戻ってくるので、読んでから承認・差し戻し・却下を選びます。Claude Code のターミナルから /moai と打っても同じ処理が動きます。

権限のプリセット：既定は「おまかせ（推奨）」

プリセットClaude Codeに許可する内容向いている場面
おまかせ（推奨・既定）ファイル編集の自動承認と、node コマンド、読み書き・検索・Web検索・Web取得・サブエージェント・スキルの使用に限定調査・執筆・レポート作成
すべて許可権限確認をすべて省略ブラウザ操作を伴う投稿まで任せる場合

まずは「おまかせ」で運用し、外部への投稿は人が行うことをおすすめします。「すべて許可」は確認なしでどんな操作も実行できる状態になるため、何をさせるかを把握したうえで、必要なときだけ選んでください。

指示の書き方の例

1つの指示は「1人の担当に、1つの成果物」に絞ると、出力が安定します。調査と執筆は分けて積み、調査の結果を見てから執筆を頼むのが基本です。

担当指示の例
SEOリサーチャー「賃貸 防災 収納」で検索上位10件の見出し構成を表にまとめ、上位にない切り口を3つ挙げて
コンテンツライター先週のSEO調査レポートの切り口1で、4000字の記事の下書きを書いて。体験談は書かない。数字には出典URLを付ける
SNSコピーライター承認済みの記事「○○」から、Instagram用キャプションを3案。本文にURLは入れない
競合アナリスト指定した3アカウントの直近の発信テーマを、公開されている投稿から整理して
グロース分析官直近4週の実績の推移を見て、伸びているチャネルと止まっているチャネルを指摘して

CLIで直接操作する

ローカル版のデータは data/*.json に保存され、画面が5秒ごとに読み直します。手で編集すると壊れやすいため、Claude Code も人も、データの更新は同梱のCLI経由で行います。主なコマンドは次のとおりです。

コマンド役割
node cli.js queue実行待ちの指示を一覧
node cli.js contextAIに渡す前提（設定・チャネル・KPI）を出力
node cli.js task-add --title "..." --body-file out.md --status review生成物を承認待ちタスクとして追加
node cli.js task-set <taskId> --status publishedタスクの状態を更新（公開済みなど）
node cli.js report-add --title "..." --kind 週次 --body-file report.mdレポートを保管
node cli.js metric --date 2026-10-02 --ch_instagram 132実績を記録（チャネルIDをそのまま指定）
node cli.js calendar-add --date 2026-10-10 --title "記事公開"カレンダーに予定を追加

長い本文はコマンドラインに直接書かず、一時ファイルに書いて --body-file で渡します。

うまく動かないとき

  • 「Claude Code が見つかりませんでした」と出る：インストール済みなら、環境変数 MOAI_CLAUDE_BIN に Claude Code の実行ファイルのパスを設定してから node server.js を起動し直す
  • ログインを求められる：node login.js --status で状態を確認し、未ログインならステップ3をやり直す
  • ポート4173が使われている：環境変数 MOAI_PORT で別のポート番号を指定して起動する
  • 画面がエラーになる：data/ のJSONを手で編集していないか確認する。更新はCLI経由で行う
  • 担当が呼ばれない：エージェント定義を ~/.claude/agents/ にコピーしたか確認する

まずはブラウザ版で流れを確認してもよい

Claude Code の準備がまだなら、インストール不要のブラウザ版で、指示を積み、まとめてコピーしてAIに貼り、結果を承認する流れを先に試せます。画面はローカル版と同じで、書き出したデータはローカル版に読み込めます。ブラウザ版での回し方は ChatGPTでのSNS運用を無料で一元管理する方法で説明しています。

よくある質問

Q. MOAIを使うのにお金はかかりますか

MOAI自体は無料のオープンソース（MITライセンス）です。Claude Code の利用には、Anthropicが案内する利用条件・料金が適用されます。

Q. Claude Codeが勝手にSNSへ投稿することはありますか

既定の「おまかせ」プリセットでは、許可されたツールが読み書き・検索・nodeコマンドなどに限られています。また同梱スキルは、承認されていないタスクを公開しないルールで動きます。生成物は承認キューに入り、人が承認するまで公開されません。

Q. 自分で作ったサブエージェントやスキルを使えますか

使えます。各担当がどのサブエージェント・スキルを呼ぶかは、担当ごとの割り当て先（初期データでは docs/seed.js の backend.target）で決まっており、ここを自分のサブエージェント名やスキル名にすると置き換えられます。新しい担当を増やす場合は claude-code/agents/ にエージェント定義を足します。担当を「おまかせ」にして指示を積めば、Claude Code が指示の内容から担当を選びます。

Q. macOSでも動きますか

Node.jsが動く環境なら動作します。ログインは node login.js、スキルとエージェントのコピーは cp コマンドで行います。

Q. 毎日決まった時刻に自動で実行できますか

MOAI自体にはスケジュール実行の機能はありません。指示を積んでおき、決まった時刻にボタンを押すか、Claude Code 側で /moai を実行する運用になります。
