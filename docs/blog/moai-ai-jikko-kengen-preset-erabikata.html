MOAIのAI自動実行の権限｜「おまかせ」と「すべて許可」の違いと選び方

公開: 2026-11-04 ・ 更新: 2026-11-04 ・ 運営: MOAI 編集部（オープンソースのMOAI開発チーム）

30秒で判断
  • 迷ったら「おまかせ（推奨）」。調べもの・執筆・MOAIのデータ更新に必要な範囲だけを許可する既定のプリセットで、ほとんどの運用はこれで足りる
  • 「すべて許可」は、ブラウザ操作を伴う投稿までAIに任せたいときだけ。権限の確認が省かれるため、隔離された環境でない限り慎重に選ぶ
  • どちらを選んでも、承認キューを通す設計は変わらない。ただし「すべて許可」では、その約束を守らせるのはAIへの指示だけになる
やらせたい作業選ぶプリセット
キーワード調査、記事や投稿文の下書き、競合調査おまかせ
実績の記録、レポートの保存おまかせ
ブラウザを操作して投稿・入力まで実行すべて許可

MOAIのローカル版には、画面のボタンひとつでClaude Codeを起動してAIに仕事をさせる機能があります。その際に選ぶのが「権限プリセット」です。この記事では、起動時の実際の引数をもとに、2つのプリセットで何が許可されるか、どの作業にどちらが向くかを整理します。

内容は、MOAIのREADMEと server.js で確認できたことに限ります。Claude Code側の仕様は公式ドキュメント（確認日 2026-11-04）で確認した範囲のみ触れます。

権限プリセットとは何か

権限プリセットとは、MOAIのサーバーがClaude Codeを起動するときに付ける「許可の範囲」の設定です。server.js の PERMISSION_PRESETS に2種類が定義されていて、実行ごとに選べます。

AIは画面の裏で claude -p として動くため、途中で人が「許可しますか？」に答える場面がありません。そのため、事前にどこまで任せるかを決めておく必要があります。これがプリセットの役割です。

「おまかせ」と「すべて許可」で許可される範囲は

「おまかせ」は編集許可モード（acceptEdits）に許可ツールの一覧を足したもの、「すべて許可」は権限確認を省くモード（bypassPermissions）です。

比べる点おまかせ（推奨・既定）すべて許可
画面上の表示名おまかせ（推奨）すべて許可（ブラウザ投稿まで任せる）
起動引数（permission-mode）acceptEditsbypassPermissions
追加で許可するツールBash(node *)、Read、Write、Edit、Glob、Grep、WebSearch、WebFetch、Task、Agent、Skill指定なし（確認自体を省く）
MOAIのデータ更新（node cli.js）可（Bash(node *)）可
調べもの・ファイルの読み書き可可
上記以外のコマンドやブラウザ操作許可リストにないため実行されない見込み確認なしで実行できる
READMEでの位置づけnode コマンドと調べもの・執筆だけを許可。既定ブラウザ操作を伴う投稿まで任せる場合に選ぶ

表の「実行されない見込み」は、Claude Code公式ドキュメント（確認日 2026-11-04）の記述にもとづく読み取りです。公式には、acceptEditsは作業フォルダ内のファイル編集などを自動承認し、それ以外のBashコマンドは確認が入ること、非対話の claude -p では許可ルールで事前承認する方法が示されています。MOAIの「おまかせ」で許可リスト外の操作がどう扱われるかは、実機で動かして確かめたわけではありません。

「すべて許可」のリスク

公式ドキュメント（確認日 2026-11-04）には、bypassPermissionsは権限の確認と安全確認を無効にし、コンテナや仮想マシンのような隔離環境での利用が想定されていること、プロンプトインジェクションや意図しない操作への保護がないことが書かれています。AIが読んだWebページの文面に誘導される可能性もゼロではないため、常用せず、必要な回だけ選ぶ運用が安全側です。

作業内容別の推奨プリセットは

作業が「文章や調査結果を作って承認キューに戻す」だけで終わるなら「おまかせ」で足ります。AI自身が外部サイトで操作を行う必要がある作業だけ、「すべて許可」の検討対象になります。

作業内容推奨理由
キーワード調査・競合調査おまかせWebSearchとWebFetchが許可に含まれる
記事・投稿文の下書きおまかせRead、Write、Editが許可に含まれ、結果は承認キューに入る
実績の記録、レポートの保存おまかせnode cli.js を使う作業で、Bash(node *) が許可されている
週次の戦略立案（「今週の戦略を立てて」）おまかせデータを読み、タスクを積むだけ
承認済みの投稿をブラウザ操作で公開すべて許可ブラウザ操作は「おまかせ」の許可リストにない
よく分からない作業おまかせ足りなければ、あとから選び直せる

投稿の自動化は、アカウント側のルールに触れる場合があります。AIに任せる前に、各サービスの利用規約を確認してください。

承認キューとの関係は｜承認なしに公開されないのか

READMEには「承認していないものが勝手に公開されることはありません」と明記されています。MOAIのスキル（claude-code/skills/moai/SKILL.md）でも、生成物は status=review で承認キューに戻し、承認されていないタスクを勝手に公開してはいけないと定められています。

注意したいのは、この約束の強制のしかたです。コード上で確認できたのは、「おまかせ」では許可ツールが絞られていること、「すべて許可」では権限確認が省かれることまでです。承認前の公開を技術的に止める仕組みは、server.js の起動引数には見当たりません。「すべて許可」では、承認の順守はAIへの指示に依存します。だからこそ、公開を伴う作業は承認キューで内容を読んでから進めるのが前提になります。

承認フローの考え方はSNS投稿の承認フローを無料で作る方法で、人が残すべき判断はAIエージェントに任せてはいけないマーケティング業務で整理しています。

ブラウザ版との違いは

権限プリセットはローカル版だけの設定です。ブラウザ版はAIを自動で動かさず、指示をまとめてコピーして、お使いのChatGPTやClaudeに貼り付ける使い方になります（READMEの比較表）。そのため、ブラウザ版では権限を選ぶ場面がありません。

比べる点ブラウザ版ローカル版
AIの自動実行なし（コピーして貼る）あり（画面のボタン）
権限プリセットなしおまかせ／すべて許可
必要なものURLを開くだけNode.js、Claude Code

導入の手順はMOAIをWindowsに入れる手順にまとめています。

実行前に必要なログイン手順は

ローカル版でAIを実行する前に、Claude Codeへのログインを一度だけ済ませます。READMEの手順は次のとおりです。

  1. Windowsは login-claude.bat をダブルクリック。macOS・Linuxは node login.js を実行する
  2. ブラウザが開くので「許可（Authorize）」を押す
  3. 画面に ✔ ログイン済み と出れば完了。状態は node login.js --status でいつでも確認できる

READMEによると、デスクトップアプリでログイン済みでも、この手順は別途必要です。アプリは自分の中に認証を持っていて、外部から起動したAIには渡さないためです。

プリセットの切り替えかた

「指示する」画面の「▶ AIに実行させる」ボタンの横にプルダウンがあり、実行ごとに選べます。初期値は「おまかせ」です。サーバー側でも、未知のプリセット名が渡された場合は「おまかせ」に戻す実装になっています。キューにある指示は上から順に実行され、生成物は承認キューに入ります。

よくある質問

Q. 迷ったら「おまかせ」と「すべて許可」のどちらを選べばいいですか

「おまかせ」を選んでください。MOAIの既定値で、調べもの・執筆・データ更新の範囲に絞られています。「すべて許可」はブラウザ操作を伴う投稿まで任せたい場合だけで足ります。

Q. 「すべて許可」にすると、承認前の記事が勝手に公開されますか

MOAIの設計とスキルの手順では、承認されていないものは公開しないと定められています。ただしこれはAIへの指示であり、「すべて許可」では権限の確認自体が省かれるため、技術的な歯止めはありません。

Q. ブラウザ版にも権限プリセットはありますか

ありません。権限プリセットはローカル版のサーバーがClaude Codeを起動するときの設定です。ブラウザ版は、指示をコピーしてお使いのAIに貼り付ける使い方になります。

Q. プリセットは実行のたびに選び直せますか

選べます。「指示する」画面の「AIに実行させる」ボタンの横にあるプルダウンで、実行ごとに切り替えられます。未知の値が渡された場合は「おまかせ」で動きます。

Q. Claude Codeにログインしていないとどうなりますか

画面にログインの案内が出て、実行できません。Windowsなら login-claude.bat、macOS・Linuxなら node login.js を一度だけ実行してください。

まずは「おまかせ」で1件実行してみる

最初は既定の「おまかせ」で、調べものや下書きを1件頼むところから始められます。ブラウザ版なら登録もインストールも要りません。
