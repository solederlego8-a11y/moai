MOAIをWindowsに入れる手順｜ブラウザ版とローカル版の始め方

無料のAIマーケティング司令室「MOAI」をWindowsで使い始めるための手順を、つまずきやすい点まで含めて整理しました。MOAIの仕組みを一通り説明する記事はすでにありますが、この記事は「Windowsのパソコンで、今日、動かすまで」に絞っています。コマンドや画面の動作は、MOAIのリポジトリ（README・ソースコード）に書かれている内容に沿っています。

この記事はMOAIの編集部が書いています。MOAIはMITライセンスのオープンソースで、利用に費用はかかりません。ただし、AIを動かすために使うClaude Codeなどのサービスの利用条件・料金は、それぞれの提供元の案内に従います。

最初に選ぶ：ブラウザ版かローカル版か

MOAIには同じ画面で動く2つのモードがあります。どちらから始めても、書き出したデータでもう一方に移れるため、迷ったらブラウザ版が安全です。

項目ブラウザ版ローカル版
準備URLを開くだけNode.jsのインストールと、ファイルの取得が必要
データの保存先そのブラウザの中自分のPCの data/*.json
AIの実行自動では動かない。指示をコピーしてAIに貼る画面の「▶ AIに実行させる」ボタンで実行
消える条件ブラウザの履歴・サイトデータの削除フォルダを削除したとき
向いている人まず試したい人毎週の運用を自動化したい人

ブラウザ版の使い方はChatGPTでのSNS運用を無料で一元管理する方法、データの保存先の違いはデータ保存先を導入前に確認する方法に詳しく書いています。ローカル版の導入に進む場合は、次の準備から始めます。

ローカル版に必要なもの

  • Node.js（無料）：MOAIのサーバーを動かすために使う。MOAIは外部パッケージに依存せず、Node.jsの標準機能だけで動く
  • Claude Code：AIをボタンで自動実行したい場合のみ。利用条件・料金は提供元（Anthropic）の案内で確認する
  • git：あると便利だが必須ではない。GitHubのページから「Download ZIP」でも取得できる

Node.jsが入っているかどうかは、コマンドプロンプトまたはPowerShellで次のコマンドを実行すると確認できます。バージョン番号が表示されれば入っています。

node -v

「認識されていません」といった表示が出る場合は、Node.jsの公式サイト（nodejs.org）から入手してインストールします。インストール後は、開いているコマンドプロンプトやPowerShellを一度閉じて開き直してから、もう一度 node -v を確認してください。開いたままだと、新しく入ったコマンドが認識されないことがあります。

手順1：MOAIを取得する

gitが使える場合は、次のコマンドで取得します。

git clone https://github.com/solederlego8-a11y/moai.git
cd moai

gitを使わない場合は、GitHubのリポジトリページで「Code」から「Download ZIP」を選び、展開してできたフォルダを使います。

置き場所の注意

ローカル版は、起動すると同じフォルダの data/ にJSONファイルを書き込みます。Windowsの「制御されたフォルダーアクセス」（Microsoftの公式機能）が有効だと、ドキュメントなど保護されたフォルダへの書き込みが制限されることがあります。書き込みでエラーが出る場合は、保護の対象外のフォルダ（たとえばユーザーフォルダ直下に新しく作ったフォルダ）に置き直すのが簡単です。設定の変更方法はWindowsのセキュリティ設定の公式ヘルプで確認してください。

手順2：起動する

取得したフォルダの中で、次のコマンドを実行します。

node server.js

起動したら、ブラウザで http://localhost:4173 を開きます。MOAIの画面が出れば成功です。止めるときは、コマンドを実行しているウィンドウで Ctrl + C を押します。

コマンドを打ちたくない場合は、フォルダにある start-moai.bat をダブルクリックしても起動します。

画面が開かないとき

  • ポート4173が使われている：環境変数 MOAI_PORT で別の番号を指定して起動し直します
  • 画面にエラーが出る：data/ のJSONを手で編集していないか確認します。壊れたJSONは画面がすぐエラーになるため、データの更新は画面かCLI（node cli.js）経由で行います
  • Node.jsのバージョンが古い可能性：node -v の結果を確認し、公式サイトの現行版に更新して再度試します

手順3：前提を書いて、最初の指示を積む

画面が開いたら、AIに実行させる前にやっておくことが2つあります。

  1. 「チャネル」で、運用しているメディア（ブログ、Instagram、Xなど）を登録する
  2. 「設定」で、ミッション・トーン・禁止ワード・運用ルールを書く

設定に書いた内容は、AIへの指示に毎回引き継がれます。書き方の例はMOAIの設定の書き方で、例文つきで説明しています。そのうえで「指示する」から、最初の依頼を日本語で書いて積みます。最初の1本は、公開しない調査系の依頼（たとえば、記事の切り口の候補を3つ挙げてもらう）にしておくと、失敗しても外に影響がありません。

手順4：AIを入れてログインする（自動実行する場合のみ）

画面のボタンでAIを動かすには、MOAI同梱のスキルとエージェント定義をClaude Codeに読ませます。Windowsでは、リポジトリのフォルダで次を実行します。

xcopy /E /I claude-code\skills\moai "%USERPROFILE%\.claude\skills\moai"
xcopy /E /I claude-code\agents "%USERPROFILE%\.claude\agents"

続いて、一度だけログインします。フォルダにある login-claude.bat をダブルクリックすると、ブラウザが開くので「許可（Authorize）」を押します。状態は次のコマンドでいつでも確認できます。

node login.js --status

デスクトップアプリでClaude Codeにログイン済みでも、この手順は別に必要です。外から起動したAIには、アプリの認証が引き継がれないためです。

Claude Codeが見つからないと言われたら

インストール済みなのに「Claude Code が見つかりませんでした」と出る場合は、環境変数 MOAI_CLAUDE_BIN にClaude Codeの実行ファイルのパスを設定してから、node server.js を起動し直します。

手順5：実行して、承認する

「指示する」画面の「▶ AIに実行させる」を押すと、キューの指示が古い順に処理されます。AIがどのツールを使い、何を調べているかが画面にそのまま表示されます。生成物は「承認キュー」に戻ってくるので、読んでから承認・差し戻し・却下を選びます。承認していないものが勝手に公開されることはありません。

権限のプリセットは、既定の「おまかせ（推奨）」のままで始めてください。このプリセットはnodeコマンドと調べもの・執筆に限って許可します。外部への投稿は、人が行う運用をおすすめします。「すべて許可」は確認なしでどんな操作も実行できる状態になるため、何をさせるかを把握したうえで、必要なときだけ選びます。

導入後の運用の全体像と、指示の書き方の例は、Claude Codeでマーケティングを自動化するやり方にまとめています。

導入したあとにやること

導入できたら、次の順で進めると運用が定着しやすくなります。

  1. 設定画面の内容を、自分の運用に合わせて書き換える
  2. 調査系の依頼を1本だけ実行し、承認キューの流れを一度通す
  3. 週に1回、設定画面から（ブラウザ版の場合は特に）データを書き出して保管する
  4. 慣れてきたら、AI担当者を自分用に追加する（MOAIのAI担当者を増やす方法）

ローカル版を使い続ける場合も、data/ フォルダのバックアップは定期的に取っておくと安心です。MOAIにはクラウド同期の機能がないため、PCの故障や誤削除に備えるのは使う人の側になります。

ブラウザ版から引っ越す・更新する

ブラウザ版のデータをローカル版に移す

すでにブラウザ版を使っていた場合は、設定画面の「データを書き出す（JSON）」でファイルを保存し、ローカル版の設定画面で「読み込む」を選びます。MOAIの書き出しファイルではないファイルを選ぶと、読み込めない旨のメッセージが出ます。移したあとも、元のブラウザ版のデータは消えないため、ローカル版で問題なく動くことを確認してから、ブラウザ版の利用をやめれば安心です。

新しい版に更新する

gitで取得した場合は、リポジトリのフォルダで git pull を実行すると最新の状態になります。ZIPで取得した場合は、新しいZIPを別のフォルダに展開し、元のフォルダの data/ をコピーして持っていく形になります。data/ はGitの管理対象外なので、更新で上書きされることはありませんが、更新前にフォルダごとバックアップを取っておくと確実です。

削除したいとき

ローカル版は、フォルダを削除すれば取り除けます。Node.jsや、Claude Codeにコピーしたスキル・エージェント定義（%USERPROFILE%\.claude 以下）は別の場所にあるため、不要なら個別に削除します。削除前に、必要なデータを書き出しておいてください。

導入前に決めておくと迷わないこと

手順そのものよりも、「何のために動かすのか」が決まっていないと、導入後に手が止まります。導入の前に、次の3点だけメモしておくことをおすすめします。

  • 運用するチャネルはどれか（ブログ、Instagram、Xなど。最初は1〜2つに絞る）
  • 最初に任せたい仕事は何か（調査、下書き、投稿文の派生など。公開に直結しないものから）
  • 公開の判断は誰が、いつ行うか（承認する人と曜日を決める）

この3点が決まっていれば、画面を開いてからの設定と最初の指示が、短時間で書けるはずです。運用全体の流れはAIマーケティングの運用ループを無料で回す手順で、計画から計測まで通して説明しています。

よくある質問

Q. Windows以外でも動きますか

Node.jsが動く環境なら動作します。macOSやLinuxでは、ログインは node login.js、スキルとエージェントのコピーは cp コマンドで行います。

Q. Node.jsを入れたくない場合はどうすればいいですか

ブラウザ版を使ってください。URLを開くだけで動き、Node.jsは不要です。ただし、AIの自動実行はできないため、指示をコピーしてAIに貼る形になります。

Q. 起動したウィンドウを閉じるとどうなりますか

サーバーが止まり、画面が開けなくなります。データは data/ に残っているので、もう一度 node server.js（または start-moai.bat）を実行すれば続きから使えます。

Q. 毎日決まった時刻に自動で実行できますか

MOAI自体にスケジュール実行の機能はありません。指示を積んでおき、決まった時刻にボタンを押すか、Claude Code側で /moai を実行する運用になります。

Q. ブラウザ版のデータをローカル版に移せますか

設定画面の「データを書き出す（JSON）」で保存し、ローカル版の「読み込む」で取り込めます。書き出したファイルは、ブラウザ版とローカル版のどちらにも読み込めます。

まず動かしてみる

手順は、コマンドを2〜3回打つだけです。先に画面の雰囲気を見たいなら、ブラウザ版をそのまま開けます。

GitHubでMOAIを入手する（無料・MIT）

インストールせずに試す場合は、ブラウザ版のMOAIを開いてください。役に立ったら、GitHubでスターを付けてもらえると開発の励みになります。無料で足りるか迷う場合は、判断基準をまとめたこちらの記事が参考になります。
